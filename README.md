# FinaTec

Offline-first, privacy-first personal finance and wealth manager built around double-entry bookkeeping.

Initial scope: financial accounts, income/expenses/transfers, assets/liabilities, net worth and traceable reports.

## Working protocol
1. Read `plan.md` and the assigned task.
2. Analyze the existing code and dependencies.
3. Present an implementation plan before editing.
4. Implement only the task scope.
5. Run tests; do not mark a task DONE without test evidence.
6. Update `PROGRESS.md` with Done / Doing / Next.
