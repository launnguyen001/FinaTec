# Data Dictionary — TASK-01

All timestamps are ISO-8601 UTC strings. IDs are opaque strings generated by the application layer. SQLite is the persistence representation; Domain uses typed values and must not depend on Drizzle/SQLite types.

## currencies

| Column | Type | Null | Rule |
|---|---|---:|---|
| code | TEXT | No | PK; uppercase 3-letter code |
| name | TEXT | No | Display name |
| minor_unit | INTEGER | No | 0–6 decimal places |
| is_active | INTEGER | No | Boolean; inactive currencies cannot be selected for new accounts |
| created_at | TEXT | No | Creation timestamp |

## ledger_settings

| Column | Type | Null | Rule |
|---|---|---:|---|
| id | INTEGER | No | PK; must equal 1 |
| base_currency_code | TEXT | No | FK currencies.code |
| created_at | TEXT | No | Creation timestamp |
| updated_at | TEXT | No | Last settings update |

The row is absent until the user completes first-run currency setup.

## accounts

| Column | Type | Null | Rule |
|---|---|---:|---|
| id | TEXT | No | PK |
| name | TEXT | No | Non-empty |
| type | TEXT | No | ASSET, LIABILITY, EQUITY, INCOME, EXPENSE |
| currency_code | TEXT | No | Fixed currency; FK currencies.code |
| is_system | INTEGER | No | Boolean; system account cannot be removed by normal UI |
| is_archived | INTEGER | No | Boolean; archival preserves history |
| created_at | TEXT | No | Creation timestamp |
| updated_at | TEXT | No | Last update timestamp |

## journal_entries

| Column | Type | Null | Rule |
|---|---|---:|---|
| id | TEXT | No | PK |
| occurred_at | TEXT | No | Business occurrence time; supports backdating |
| description | TEXT | Yes | Optional human-readable description |
| status | TEXT | No | DRAFT or POSTED |
| base_currency_code | TEXT | No | FK currencies.code; immutable snapshot on posting |
| idempotency_key | TEXT | Yes | Unique when present |
| reversal_of_id | TEXT | Yes | FK self; unique when present |
| created_at | TEXT | No | Creation timestamp |
| posted_at | TEXT | Yes | Null for draft; required for posted |

## journal_lines

| Column | Type | Null | Rule |
|---|---|---:|---|
| id | TEXT | No | PK |
| entry_id | TEXT | No | FK journal_entries.id |
| line_number | INTEGER | No | Positive; unique per entry |
| account_id | TEXT | No | Composite FK accounts(id,currency_code) |
| currency_code | TEXT | No | Native line currency; must match account currency |
| side | TEXT | No | DEBIT or CREDIT |
| amount_minor | INTEGER | No | Positive native amount in minor units |
| fx_rate_numerator | TEXT | No | Positive integer numerator |
| fx_rate_denominator | TEXT | No | Positive integer denominator |
| base_amount_minor | INTEGER | No | Converted base-currency amount, rounded half-up |
| memo | TEXT | Yes | Optional line memo |
| created_at | TEXT | No | Creation timestamp |

## Persistence limits

The Domain `Money` value object uses `bigint`. Before writing to SQLite INTEGER through the JavaScript driver, the adapter validates `Number.isSafeInteger` range. Amounts outside this limit are rejected, never truncated or coerced.
